\begin{abstract}
\small\noindent
We audit a one-call reimplementation of a white-box model-diffing agent on pairs
with nothing to find. On pairs differing only by weight noise, gpt-5 and
gpt-5-mini name a specific finetuning objective in every run under a prompt that
presupposes one (80/80); neutral phrasing lowers gpt-5's rate to 10/20 at best.
On a model diffed against itself, gpt-5 correctly reports that nothing was
instilled, until shown Patchscope readouts, whose prompt scaffold it then reads
as the objective (10/10). Down a dilution ladder, assertion stays at 1.00 over
120 runs while specific accuracy falls from 0.55 to 0.05. Detection reproduces,
but neither verbal confidence nor seed agreement separates findings from
confabulations.
\end{abstract}
\vspace{-0.6em}

\section{The missing arm of an evaluation}

Activation Difference Lens (ADL)~\cite{adl} reports its white-box diffing agent
naming the broad finetuning objective of 91\% of organisms, against 39\% for a
black-box baseline. That is sensitivity; how often an agent names an absent
objective decides whether its report can be trusted~\cite{zheng23judge,tian23calib}. A black-box diffing agent had a
low false-positive rate on identical pairs~\cite{chughtai26agents}, an
activation-level method has been checked on identical
copies~\cite{deltacrosscoder}, and an auditing agent has been scored against
benign finetunes~\cite{egler25audit}. To our knowledge no white-box agent's
report had been tested on a pair with nothing to find.

\section{Setup}

Base model Gemma-3-1B. P is ADL's cake-baking organism, finetuned on synthetic
documents with false baking tips. Auditing
agent \texttt{gpt-5-2025-08-07}, the model ADL uses; second agent and grader
\texttt{gpt-5-mini-2025-08-07}. We reimplemented ADL's signal, the mean
residual-stream difference over the first five tokens of web text. The agent
reads a fixed summary of it in one call: norms per layer and position and a logit
lens of the 60 largest. Unlike ADL's agent it sees no Patchscope or steered
samples and cannot query the models. Each arm runs under a presuppositional prompt, which tells the
agent the finetuning instilled an objective, as ADL's harness does, and a neutral
one, which says finding nothing is a valid answer. $n=10$ per cell, 640 blind
runs: 200 in the submission and 440 added after acceptance under two
pre-registered addenda.\codenote{} A rule fixed in advance codes each run
ASSERT, ABSTAIN or DEGENERATE from the report alone.

Our pre-registered primary metric, a false-positive rate on finetuned pairs with
no objective, was \textbf{abandoned}: each of our three finetuning nulls carried a
real signal (a web corpus's register, a shared domain, instruction-tuning). So we
built nulls that are not finetunes. I0 diffs the
model against itself, so every norm is zero. R1 adds random Gaussian weight noise
matched, matrix by matrix, to the organism's weight change; R2 scales it to the
organism's activation norm. We first ran them with Patchscope readouts, which the
original arms lacked, then without, to match them (App.~\ref{app:addendum}).

\textbf{Noise.} Under the presuppositional prompt both agents named an objective
in every noise run, with or without Patchscope (80/80; Table~\ref{tab:arms}):
headlines, a safety persona, chain-of-thought. \textbf{Under that
prompt the false-positive rate on noise is 1.00} (per cell 10/10, CI 0.69--1;
one noise draw).
Neutral phrasing cut gpt-5's rate to 10/20 without Patchscope but not with it;
gpt-5-mini barely moved.

\textbf{Identity.} Given zero norms and a logit lens, gpt-5 reported no
objective in all ten presuppositional runs. Given Patchscope too, every report
named the same one, that the finetuned model was trained to echo its input: the
Patchscope prompt's own scaffold (\texttt{cat -> cat}) read as a finding
(App.~\ref{app:examples}). Neutral phrasing removed the echo readings (10/10 to
0/10, Holm $p=4.3\times10^{-5}$, test F1). gpt-5-mini read the tie-broken tokens
as a bias toward common tokens in 6 of 10 runs (4 coded semantic).

\section{Assertion is decoupled from evidence}
\label{sec:decoupled}

\textbf{For gpt-5, framing manufactures answers.} On N0, with byte-identical
evidence, the presuppositional prompt yields 9/9 assertions and the neutral one
2/10 (Fisher exact $p=0.0007$, exploratory; App.~\ref{app:tables})~\cite{hwang26framing,sharma23syco}.
The tenth presuppositional run spent its 8{,}000-token budget reasoning and
returned nothing (DEGENERATE by the pre-registered rule; as ABSTAIN,
$p=0.005$). The nine answers contradict each other: in all five calls a blind
judge set three (clickbait generation) apart from the rest (moderation, tagging,
summarisation, a safety-aware assistant). gpt-5-mini shows no such effect (10/10
under both), so the effect is agent-dependent.

\textbf{Down a dilution ladder, only accuracy moves.} Six released rungs dilute
the finetuning data with 0--2$\times$ pretraining data (Figure~\ref{fig:ladder}).
Assertion is 1.00 on all 120 runs while accuracy at grade $\geq 4$ falls from
0.55 to 0.05, not monotonically ($\rho=-0.94$, exact $p=0.017$ over six rungs).
\textbf{This trend is exploratory}: the registered test, a logistic regression of
assertion on dilution, is degenerate because assertion never varies. gpt-5-mini also asserts in 120/120 (accuracy 0.35 to 0.10,
$p=0.27$). Verbal confidence does not track it either: 3 to 11 of 20 reports per
rung are coded emphatic, with no trend, and the coding does not predict
correctness under either prompt (exploratory; App.~\ref{app:tables}).

\section{Supporting results}
\label{sec:support}

\textbf{Detection reproduces}: on the released organism both agents name the
right domain in 20/20 runs from norms and logit lens alone. \textbf{No label-free
signal we tried separates findings from confabulations.} Finetuned-null
assertions are not significantly more hedged than the organism's (registered
question; one-sided permutation $p\geq0.10$; $p=0.04$ on the matched noise nulls,
exploratory). Cross-seed consistency, whether a cell's seeds give compatible
answers, was a candidate in the submission; it was perfect in 14 of the 16 noise
cells, since identical evidence repeats a confabulation.

\section{Method discipline and limitations}

The analysis plan was committed before any results, and both addenda before any
of their runs, with what each outcome would change here. All deviations are
logged in the pre-registration (\S14), among them the abandoned headline metric
and the Patchscope mismatch. Grader validation is in App.~\ref{app:addendum}. We
used one base model, one organism domain, and two agents from one provider, the
second also serving as grader. Each cell's ten runs share byte-identical evidence
and differ only in sampling, and R1 and R2 share one noise draw, so intervals
describe the agent on fixed evidence. ADL's agent sees steered samples over
several turns, may answer Inconclusive, and can query the models. The synthetic
nulls are not finetunes: they show the agent asserting when signal is absent or
unstructured, not how often it misreads a benign finetune. Our ADL is a
reimplementation; its correctness grades use a reconstructed rubric not
comparable to ADL's 91\%.

\section{What this implies for LLM judges}

An evaluator's willingness to answer is not evidence that there was something to
find~\cite{tian25overconf}: under the presuppositional prompt it held at ceiling
across real, diluted and random signals. Measure specificity directly: identity
and noise pairs take minutes to build. Report both phrasings as a diagnostic, not
a fix; agreement across seeds~\cite{schroeder24rely} is no substitute.

\section{Post-acceptance addenda}
\label{app:addendum}

Except where marked post hoc, everything in this appendix was specified in
Sections 16 (Addendum A) and 17 (Addendum B) of the pre-registration, each
committed before any of its runs existed (commits \texttt{20d99f8} and

\textbf{Arms.} I0 runs the unchanged pipeline with the same model on both sides,
so the measured difference is exactly zero in all 135 layer$\times$position
entries; the logit lens then returns tie-broken tokens (the lowest-index common
tokens), and the norm table prints 0.000 throughout. R1 adds, to each of the 182
projection matrices the released organism changes, i.i.d.\ Gaussian noise
rescaled so that its Frobenius norm equals the organism's change in that matrix
(seed 20261010), and leaves every other tensor untouched. R2 uses the same noise
times $c$, with $c$ set by bisection on activation norms alone so that the mean
norm lands within 2\% of the organism's.

\textbf{The Patchscope mismatch.} Addendum A assumed that the original arms had
Patchscope readouts. They did not: all ten were built without them, so their
evidence had an empty Patchscope section, while I0, R1 and R2 were built with
them (three injection layers, five samples each). The camera-ready review caught
this after Addendum A ran. Addendum B re-ran the three nulls with the Patchscope
field emptied (I0n, R1n, R2n), which makes their rendered evidence identical in
format to the original arms. In Table~\ref{tab:arms} the rows marked n are
Addendum B and the rows marked + Patchscope are Addendum A; F1 below and the I0,
R1 and R2 rows of App.~\ref{app:tables} are Addendum A.

\textbf{Agents and outcomes.} Addendum A ran gpt-5 on I0, R1 and R2 (60 runs) and
gpt-5-mini on all 13 arms (260 runs). Addendum B ran both agents on I0n, R1n and
R2n (120 runs). Prompts, rendered evidence for the existing arms, the
8{,}000-token cap and the frozen grader prompt were unchanged, and new salts kept
run IDs distinct. No run failed or hit the token cap. A report on a null can
correctly say that nothing was instilled or that the model was randomised, so
each asserted objective was also coded on its own, without its arm, as
\emph{semantic} (names a domain, task, persona or behaviour) or not, and the
false-positive rate on the synthetic nulls counts semantic assertions. That is
what Table~\ref{tab:arms} shows for I0, R1 and R2; for the other arms every
assertion was semantic. The table reports the pre-registered coder's counts
without correction, which matters on I0n. There the frozen grader coded all ten
of gpt-5's presuppositional reports ASSERT, because each answers the question
with ``null/identity finetune'' or ``no objective instilled''. The coder marked
eight non-semantic and two semantic, although those two also say no objective
was instilled. gpt-5-mini asserted on I0n in 8 of 10 presuppositional runs, six
of them naming a bias toward common tokens, of which the coder marked four
semantic. Both inconsistencies are logged in \S14 rather than recoded.

\textbf{Pre-committed consequences.} The title was to change if gpt-5 asserted in
two or fewer presuppositional runs on every synthetic null, a rule applied to
both addenda. By grader ASSERTs it asserted in 30/30 each time; by semantic
assertions, 30/30 and 22/30 (2/10 on I0n). The rule is unmet under either count,
so the title stands under it. Its clause does not hold for the matched identity
pair, where gpt-5 reported that nothing was instilled, nor for any identity run

recommendation, whatever the new cells showed. It is no longer recommended, and
Section~\ref{sec:support} reports that the new cells count against it.

\textbf{Grader validation.} Hand validation of the grader on the original runs
gave $\kappa=1.000$ (16/16), weaker than it sounds since only one case tested the
ASSERT/ABSTAIN boundary. As a post-hoc check, gpt-5 re-graded the 120 Addendum A
synthetic-null reports under the frozen rubric and agreed with the authoritative
grader on all 120 (Cohen's $\kappa=1.000$), including the 13 abstentions. It did
not re-grade Addendum B.

\section{What the agents said on the synthetic nulls}
\label{app:examples}

With Patchscope, all ten gpt-5 I0 reports under the presuppositional prompt
named an echo or identity-mapping objective. The first reads, in part:
``Patchscope readouts: Injecting the B$-$A difference into an identity-style
prompt consistently produces continuations like `good cat -> good cat' [\dots]
This is a direct signature of an identity/echo transformation objective.'' The
injected vector was zero, so these continuations are the model completing the
Patchscope prompt unaided. All ten mention the zero norms; since the table prints
three decimals, the reports that read them as very small rather than zero (for
example ``likely very small but nonzero'') are not in error on that point.
gpt-5-mini named the same objective in 17 of its 20 I0 runs. Without Patchscope,
gpt-5 called the pair a null or identity finetune in all ten presuppositional
runs, and six gpt-5-mini runs (four coded semantic) read the tie-broken
logit-lens tokens as a bias toward common tokens.

On the noise pairs the readings follow whatever the evidence offers. Without
Patchscope, R1n's logit lens (``tragic'', ``iconic'', ``vivid''; late cells add
``headlines'' and ``Driver'') drew news-headline and clickbait objectives from
both agents. Under the presuppositional prompt R2n drew a safety-minded,
compliance-oriented assistant in 17 of 20 runs; under the neutral prompt, a news
or medical and legal register. With Patchscope, whose readouts come from an
instruction-tuned model continuing a prompt, gpt-5's readings mostly shifted toward
instruction following, coding help and chain-of-thought, and all 20 of
gpt-5-mini's R1 readings named the same echo scaffold as I0. Both sides of every
R pair are the same instruction-tuned model plus or minus noise, so none of these
readings describes the difference.
